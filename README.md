# Isa Lash Designer 🦋

Site da **Isadora Cunha**, lash designer certificada em Taguatinga Norte, Brasília - DF.

**Site no ar:** https://cauamigueldev.github.io/isa-lash-designer/

## Sobre o site

Página única para mostrar os trabalhos da Isa e levar a cliente direto ao agendamento pelo WhatsApp.

- **Trabalhos:** galeria com fotos reais de clientes, com ampliação ao toque.
- **Serviços:** extensão de cílios (fio a fio, Volume Brasileiro, 4D/5D, Egípcio, Fox Eyes, Efeito Rímel), lash lifting, manutenção, limpeza de pele e curso de cílios para iniciantes.
- **Agendamento:** a cliente escolhe o serviço, o dia, o período e o nome. O WhatsApp abre com a mensagem pronta, e uma prévia da conversa aparece enquanto ela preenche.
- **Sobre, dúvidas e localização:** apresentação da Isa, perguntas frequentes com cuidados pós-aplicação e mapa com o botão "Como chegar".

## Tecnologia

- HTML, CSS e JavaScript puros em um único arquivo (`index.html`), sem build e sem dependências para instalar.
- Fontes Cormorant Garamond e Outfit (Google Fonts) e ícones [Phosphor](https://phosphoricons.com/).
- Animações de rolagem, menu que acompanha a seção e layout adaptado para celular.
- Respeita a opção do sistema de reduzir movimento.
- Publicado com GitHub Pages.

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python -m http.server 5391
```

Depois acesse http://localhost:5391.
